# IranOSINT Bot
ربات فارسی تلگرام با FastAPI و PostgreSQL برای بررسی قالب شماره موبایل ایران و پیش‌شماره تخصیص اولیه.

تمام فایل‌های برنامه در ریشه مخزن قرار دارند؛ هیچ پوشه app یا پوشه تو در تو لازم نیست.

امکانات: وب‌هوک تلگرام، ثبت کاربران در PostgreSQL، بررسی قالب شماره و نمایش پیش‌شماره اولیه، آمار مدیر.

این پروژه هویت صاحب شماره، کد ملی، نشانی، اطلاعات بانکی یا داده‌های خصوصی را جستجو یا استخراج نمی‌کند.

در Render، Blueprint را از render.yaml بسازید و BOT_TOKEN، WEBHOOK_SECRET، WEBHOOK_BASE_URL و ADMIN_IDS را در Environment تنظیم کنید. DATABASE_URL از دیتابیس Render متصل می‌شود و وب‌هوک هنگام شروع سرویس تنظیم خواهد شد.
